# clipprot

Clip URLs and prot query parts with stable normalization.

**Site:** https://theworker02.github.io/clipprot/

## Install / run

```bash
git clone https://github.com/theworker02/clipprot.git
cd clipprot
node src/cli.js
node --test
```
